## Что умеет

| | |
|---|---|
| **ИИ для выделенного текста** — <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>A</kbd> | Улучшить, сократить, исправить ошибки, деловой стиль и свои кнопки. Результат вставляется на место выделенного |
| **Переводчик** — <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Z</kbd> | Перевод выделенного без ИИ и токенов, с вставкой обратно |
| **Текст с экрана** — <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd> | Обведи область — текст в буфере. Распознаёт Windows, без интернета |
| **Панель** — <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> | Заметки и большое окно для длинного текста, заготовки, калькулятор с курсами ЦБ, хранилище паролей с Windows Hello |

**ИИ на выбор:** cloud.ru (GigaChat и другие), Алиса AI, DeepSeek
или модель на своём компьютере (Ollama, LM Studio). Работает в России без VPN.
Как получить ключ — [пошаговая инструкция](docs/ai-keys.md).

## Установка

1. Скачай [Larchik-Setup.exe](https://github.com/belart16/larchik/releases/latest/download/Larchik-Setup.exe) и запусти.
   Права администратора не нужны.
2. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
   У программы пока нет платной цифровой подписи; это предупреждение о незнакомом издателе, а не об угрозе.
3. Мастер первого запуска покажет сочетания клавиш и поможет подключить ИИ.

Larchik обновляется сам: Настройки → «Обновления». Требования: Windows 10 (1809+) или Windows 11, 64 бит.

## Данные

- Заметки, заготовки и настройки — обычные файлы на твоём компьютере.
- Пароли и ключи ИИ зашифрованы Windows и на другом ПК бесполезны.
- В интернет уходит только то, чем ты пользуешься: текст для ИИ — в выбранный сервис,
  текст для перевода — в Google Translate (резерв — MyMemory) или в твой ИИ, только после твоего разрешения; курсы валют — с сайта ЦБ РФ,
  и раз в день номер последней версии с GitHub (выключается в настройках).
- Нет рекламы, аналитики и сбора статистики.

## Удаление

«Параметры → Приложения → Larchik → Удалить». В конце программа спросит, стирать ли заметки и пароли
(по умолчанию они сохраняются).

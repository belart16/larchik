# Как подключить ИИ к Larchik

Larchik не встраивает чужие ключи: ИИ работает через **твой** API-ключ одного из сервисов.
Ключ вставляется только в окно Larchik (Настройки → ИИ → «Подключение»), хранится на этом
компьютере в зашифрованном виде (Windows DPAPI) и никуда, кроме выбранного сервиса, не уходит.

> Никому не пересылай ключ — ни в чат, ни в поддержку. Если ключ куда-то утёк,
> удали его в кабинете сервиса и создай новый.

Какой выбрать:

| Сервис | Плюсы | Что нужно |
|---|---|---|
| **cloud.ru** (GigaChat и др.) — рекомендуем | GigaChat работает в России, оплата в рублях, хороший русский; там же Claude и GPT | аккаунт cloud.ru, пополненный баланс |
| **Алиса AI (Яндекс)** | сильный русский, оплата в рублях | аккаунт Yandex Cloud, ключ + ID каталога |
| **OpenRouter** | есть бесплатные модели (около 50 запросов в день) | аккаунт openrouter.ai |
| **DeepSeek** | логика, код, объяснения | аккаунт и пополненный баланс |
| **Своя модель** | текст не уходит с компьютера | установленная Ollama или LM Studio |

---

## cloud.ru — GigaChat, Claude, GPT и др.

1. Зарегистрируйся на [console.cloud.ru](https://console.cloud.ru) и пополни баланс
   (без денег на счёте сервис отвечает «Недостаточно средств»).
2. Открой **Пользователи → Сервисные аккаунты** и создай сервисный аккаунт.
3. В нём нажми **«Создать API-ключ»** и выбери сервис **Foundation Models**.
   Нужен именно *API-ключ* — «ключ доступа» (access key) не подойдёт.
4. Скопируй ключ: его показывают один раз.
5. В Larchik: Настройки → ИИ → «Подключение» → провайдер **cloud.ru** → вставь ключ →
   «Проверить и подключить».

По умолчанию выбрана модель GigaChat. Кнопка «Список» покажет всё, что есть на платформе.
Модели с пометкой **«внешняя»** (Claude, GPT, Gemini) cloud.ru перепродаёт: текст уходит их
разработчику за рубеж, а цена обычно заметно выше — сверь её в прайсе cloud.ru.
Для личных и рабочих данных лучше GigaChat или открытые модели без пометки.

## Алиса AI — Яндекс

1. Зайди в [console.yandex.cloud](https://console.yandex.cloud), создай платёжный аккаунт.
2. Слева вверху открой свой каталог и скопируй его **идентификатор** (обычно начинается с `b1g…`).
3. В каталоге создай **сервисный аккаунт** с ролью `ai.languageModels.user`.
4. У сервисного аккаунта создай **API-ключ** и скопируй его.
5. В Larchik: провайдер **Алиса AI** → ID каталога + ключ → «Проверить и подключить».

## OpenRouter — бесплатные модели

1. Войди на [openrouter.ai](https://openrouter.ai) (можно через Google).
2. Открой **Keys → Create key**, скопируй ключ.
3. В Larchik: провайдер **OpenRouter** → вставь ключ → кнопка **«Бесплатные»** → выбери модель
   с окончанием `:free` → «Проверить и подключить».
4. Набор бесплатных моделей меняется. Если модель перестала отвечать — снова нажми «Бесплатные».

## DeepSeek

1. Зарегистрируйся на [platform.deepseek.com](https://platform.deepseek.com) и пополни баланс.
2. **API keys → Create new API key**, скопируй ключ.
3. В Larchik: провайдер **DeepSeek** → ключ → «Проверить и подключить».

## Своя модель на компьютере

1. Установи [Ollama](https://ollama.com) и скачай модель, например `ollama pull qwen2.5:7b`.
2. В Larchik: провайдер **«Свой адрес»** → адрес `http://localhost:11434/v1` → «Список» →
   выбери модель. Ключ не нужен.

**Не получилось?** Larchik показывает понятную причину под кнопкой «Проверить и подключить»
(неверный ключ, пустой баланс, нет модели). Если причина непонятна —
[напиши об этом](https://github.com/belart16/larchik/issues).

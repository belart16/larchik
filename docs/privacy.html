Коротко: Larchik работает на твоём компьютере. Он не собирает статистику, не показывает рекламу и не передаёт правообладателю (Belart Product) ни твои тексты, ни заметки, ни пароли, ни ключи. В интернет уходит только то, что нужно для функции, которой ты пользуешься в эту минуту, — и только туда, куда ты сам выбрал.

1.Что хранится на компьютере

Всё хранится в папке %AppData%\Larchik твоей учётной записи Windows:

Данные Как хранятся
Заметки обычные текстовые файлы .md
Заготовки, кнопки ИИ, настройки файлы .json
Хранилище паролей зашифровано Windows (DPAPI): на другом компьютере или под другим пользователем не расшифровывается
Ключи доступа к сервисам ИИ зашифрованы Windows (DPAPI)
Курсы валют файл rates.json — копия опубликованных курсов Банка России
Журнал ошибок папка logs: только технические записи (версия программы и Windows, описание ошибки). Без твоих текстов. Имя пользователя Windows в путях заменяется на <user>

Правообладатель не имеет доступа к этой папке.

2.Что и когда уходит в интернет

Передача идёт по защищённому соединению (HTTPS), кроме локальной модели ИИ на твоём компьютере (localhost).

Когда Что передаётся Куда
Ты отправляешь текст ИИ (вопрос, кнопки «Улучшить», «Короче» и т. п.) этот текст и твой ключ доступа только в сервис ИИ, который ты подключил: cloud.ru, Яндекс, DeepSeek или адрес, указанный тобой
Ты переводишь текст текст для перевода Google Translate; если он недоступен — MyMemory; если и он недоступен, а ИИ подключён — в твой ИИ. Перевод начинает работать только после твоего разрешения. В режиме «Через мой ИИ» Google не используется
Ты считаешь валюты (например, «100 usd в руб») ничего о тебе — только запрос курсов сайт Банка России, не чаще раза в несколько часов
Раз в день (выключается: Настройки → Обновления) запрос номера последней версии GitHub
Ты нажимаешь «Обновить» загрузка установщика новой версии GitHub
Ты нажимаешь «Сообщить о проблеме» или «Предложить идею» ничего автоматически: открывается страница обратной связи на сайте, в адресе которой есть только версии Larchik и Windows. Сообщение уходит, только когда ты сам заполнишь форму и нажмёшь «Отправить» Яндекс Формы → Belart Product

Сервисы ИИ, переводчики, Банк России, GitHub и Яндекс — независимые компании со своими правилами обработки данных. Не отправляй через них то, что не готов им доверить. Модели ИИ некоторых сервисов (например, «внешние» модели на cloud.ru) обрабатывают текст за пределами России — Larchik помечает их в списке моделей.

3.Что программа видит, но не хранит и не передаёт

  • Клавиатура. Если у заготовки задан набор символов (например, 1у8), Larchik следит за нажатыми клавишами, чтобы заметить этот набор. В памяти держатся только коды последних ~30 клавиш; они не записываются на диск и никуда не отправляются. Если ни у одной заготовки нет набора, слежение выключено полностью.
  • Буфер обмена. Используется, когда ты сам нажимаешь сочетание клавиш или кнопку («Вставить», «Скопировать»). После вставки прежнее содержимое буфера возвращается. Скопированный из хранилища пароль стирается из буфера через 30 секунд.
  • Экран. Снимок делается, только когда ты вызываешь «Текст с экрана». Текст распознаёт сама Windows без интернета; снимок не сохраняется.
  • Microsoft Word. При вставке результата в Word программа обращается к Word, чтобы не склеить абзацы. Документ не читается целиком и не передаётся.

4.Чего Larchik не делает

  • не собирает статистику и аналитику, не использует идентификаторы устройства;
  • не показывает рекламу;
  • не передаёт данные правообладателю сам и не продаёт их — Belart Product получает только то, что ты отправил через форму обратной связи;
  • не требует регистрации и аккаунта.

5.Сайт и обратная связь

Сайт Larchik размещён на GitHub Pages. GitHub может записывать технические сведения о посещениях (например, IP-адрес) по своим правилам. Сам сайт не использует cookie и счётчики; номер последней версии на странице запрашивается у GitHub.

Сообщения о проблемах и идеи принимаются через формы сервиса Яндекс Формы, встроенные в страницу «Обратная связь». Данные форм хранятся у Яндекса в России; на этой странице Яндекс может использовать собственные cookie по своим правилам.

  • Что попадает в сообщение: то, что ты сам написал или приложил (текст, скриншот, отчёт об ошибке), а также версии Larchik и Windows, если ты открыл форму из программы.
  • Email указывать не обязательно — он нужен, только если ты хочешь получить ответ. Он используется лишь для ответа на твоё сообщение и никому не передаётся.
  • Отчёт об ошибке Larchik не отправляет сам: он копируется в буфер обмена, и ты видишь его целиком, прежде чем вставить в форму. В нём только версии программы и Windows, время и техническое описание ошибки — без заметок, паролей и ключей.
  • Зачем: чтобы исправлять ошибки и решать, что добавить в Larchik. Сообщения хранятся, пока нужны для этого, и удаляются по твоей просьбе — напиши об этом через ту же форму.

6.Удаление данных

  • Удали программу: «Параметры → Приложения → Larchik → Удалить». В конце программа спросит, стереть ли папку с данными.
  • Или удали папку %AppData%\Larchik вручную.
  • Ключ ИИ можно удалить в Настройки → ИИ → «Подключение» → «Удалить сохранённый ключ».

Данные, уже отправленные в сторонние сервисы, хранятся по правилам этих сервисов.

7.Дети

Larchik не предназначен специально для детей и не собирает данные о возрасте.

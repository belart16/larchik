Подключи ИИ, который тебе подходит

Larchik работает с твоим API-ключом: ключ хранится только на твоём компьютере в зашифрованном виде. Без ИИ работают переводчик, текст с экрана, калькулятор, заметки и пароли.

Честно о данных

Программа видит буфер обмена и хранит пароли, поэтому вот полный список того, что уходит в интернет.

Уходит в сеть — только когда ты этим пользуешься

  • Текст для ИИ — в выбранный тобой сервис ИИ.
  • Текст для перевода — в Google Translate.
  • Курсы валют загружаются с сайта ЦБ РФ.
  • Номер последней версии — раз в день с GitHub; выключается в настройках.

Остаётся на компьютере

  • Заметки, заготовки, настройки — обычные файлы в твоей папке.
  • Пароли и ключи ИИ — зашифрованы Windows, на другом ПК бесполезны.
  • Текст с экрана распознаётся без интернета.
  • Нет рекламы, аналитики и сбора статистики.

Установка за минуту

Права администратора не нужны. Larchik ставится только для твоей учётной записи и обновляется сам.

  1. Скачай Larchik-Setup.exe и запусти.
  2. Если появится синее окно «Система Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае».
  3. Мастер первого запуска покажет сочетания клавиш и поможет подключить ИИ. Значок Larchik живёт в трее, рядом с часами.
Почему Windows предупреждает? У Larchik пока нет платной цифровой подписи, а Windows осторожна с новыми программами, пока их не скачают многие. Это предупреждение о незнакомом издателе, а не об угрозе.

Вопросы

Это бесплатно?

Да. Сам Larchik бесплатный. Платить можно только сервису ИИ, если выберешь платный: GigaChat стоит недорого, у OpenRouter есть бесплатные модели.

Нужен ли VPN?

Нет. cloud.ru и Алиса AI работают в России. Переводчик и текст с экрана тоже работают без VPN.

Как удалить?

«Параметры → Приложения → Larchik → Удалить». В конце программа спросит, стирать ли заметки и пароли; по умолчанию они остаются.

Нашёл ошибку или есть идея

Напиши в обсуждениях проекта — или в самой программе: Настройки → «Сообщить об ошибке».

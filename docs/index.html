    Данные

    Честно о данных. Полный список.

    Программа видит буфер обмена и хранит пароли, поэтому рассказываем всё. Подробно - в политике конфиденциальности.

    Остаётся на компьютере

    • Заметки, заготовки, настройки - обычные файлы в твоей папке.
    • Пароли и ключи ИИ зашифрованы Windows, на другом ПК бесполезны.
    • Текст с экрана распознаётся без интернета.
    • Нет рекламы, аналитики и сбора статистики.

    Уходит в сеть, только когда ты этим пользуешься

    • Текст для ИИ - в выбранный тобой сервис.
    • Текст для перевода - в Google Translate (резерв - MyMemory) или в твой ИИ; только после твоего разрешения.
    • Курсы валют - с сайта ЦБ РФ.
    • Номер последней версии - раз в день с GitHub; выключается.
    Установка

    Минута - и всё работает.

    1. Скачай и запусти

      Larchik-Setup.exe - на компьютере. Права администратора не нужны.

    2. Если Windows предупредит

      В окне «Система Windows защитила ваш компьютер» - «Подробнее» → «Выполнить в любом случае». У программы пока нет платной цифровой подписи: это предупреждение о незнакомом издателе, а не об угрозе.

    3. Познакомься

      Мастер первого запуска покажет сочетания клавиш и поможет подключить ИИ. Значок Larchik живёт в трее, рядом с часами.
